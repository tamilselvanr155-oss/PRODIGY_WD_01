# 🚀 Interactive Navigation Menu 
An interactive, responsive, and modern fixed navigation bar built with **HTML**, **CSS**, and **JavaScript**. Developed as part of the Web Development Internship at **Prodigy InfoTech**.

## ✨ Features
- **Fixed Position:** Stays accessible at the top of the viewport across all pages/sections.
- **Dynamic Scroll Effects:** Utilizes JavaScript event listeners to adjust backdrop blur, padding, border glow, and background opacity when scrolling down.
- **Glassmorphism UI/UX:** Dark-mode tech aesthetic using CSS modern variables and backdrop filters.
- **Interactive Hover Styles:** Glowing underline indicators and subtle background highlighting on menu items.
- **Pure Vanilla Code:** No external frameworks or libraries required—lightweight and fast.


## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox, transitions, and glassmorphism styling.
- **JavaScript (ES6):** Scroll detection DOM manipulation.
